# 上游协议探测

管理员编辑一个对话模型部署，在“上游协议探测”中开启“保存连接变更后自动探测”。开关随模型保存；也可以点击“立即探测”，它使用已保存的配置。已有部署默认关闭自动探测，不会因升级批量调用供应商。

验证通过的 Chat、Responses、Messages 自动增加对应的透传入口，继续使用同一个部署、模型授权、价格和预算检查。普通接口仍使用原先选定的上游协议。供应商可能自行转换协议；这里验证的是其对外接口，没有假定其底层模型原生使用该协议。

## 验证范围

每种协议最多四次短请求：普通文字回复、完整文本流、一个固定函数调用、关联工具 ID 的结果回传。检查响应结构、协议终态和工具关联，HTTP 200、HTML 页面或缺少结束事件不能算通过。只发送固定英文测试内容，不发送用户历史或执行真实工具。每步最多 30 秒，响应最多 1 MiB。

三种协议最多同时探测，自动任务顺序处理部署；不同部署的手动探测互不阻塞。探测使用最长 150 秒的单部署租约（整轮请求最多 125 秒），等待上游时不占用数据库连接。上游可能收费，这些管理员诊断不作为用户推理扣费。没有定时调用供应商的健康复测：维护循环比较配置摘要并按供应商去重读取当前凭据，地址、凭据或上游模型改变才重新探测。只改价格或展示名称不重复调用。数据库无法保存结果时，当前进程也不会自动反复调用；管理员可手动重试。

此验证不证明图片、内置搜索、后台任务、Token 计数或流式工具调用均受支持。结果只添加三种对话 create 入口，不增加额外任务操作。

## 结果与配置安全

- 测试输出达到 256 Token 上限时显示“未能确定”，不自动加大额度重试，也不撤销相同连接的旧验证。Responses 使用 `store:false` 和加密推理项完成无服务端存储的工具续轮。
- 临时网络故障、429、5xx 显示“暂时失败”；相同连接以前已验证的额外入口保留。
- 确定的协议不符或请求被拒绝撤销本次探测对应的额外证明；管理员原有显式上游配置不被自动修改。
- 模型、地址或凭据发生变化，旧证明立即失效，不能等待下一轮探测才撤销。
- 探测期间配置被改动，结果丢弃。数据库只原子更新探测元数据，不覆盖其他配置；不会重新创建已删除部署。
- 结果只保存固定诊断、HTTP 状态、时间和服务端摘要，不保存正文或密钥；对页面隐藏摘要。客户端提交的探测证明被忽略。
- 手动接口 `POST /model/protocol_probe` 只接收已保存部署 ID，限平台管理员。200 代表检测完成，具体能力必须查看逐协议结果；404 为部署不存在，409 为已有探测或配置变化，400 为配置不适合探测，503 为存储不可用。

调试台和“我的模型”的 API 接入使用后端实际绑定生成选择项，区分标准调用和协议透传，主标签展示协议、次行展示路径。示例提示词始终为英文，中文/英文界面均保留用户原文。

## 验证边界

单元测试校验解析和错误分类；后台回归使用真实 HTTP、PostgreSQL、严格协议测试上游，验证权限、保存、并发编辑、写库失败、凭据轮换、账单及三协议工具往返。双语浏览器验证保存触发、手动复测、10 个对话入口的页面 curl、窄屏布局及 Chat 透传对话。隔离测试没有使用商业供应商密钥，不代表所有线上模型都已通过；它们需管理员在实际连接上开启探测后取得结果。
