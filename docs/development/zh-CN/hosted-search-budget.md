# 联网搜索计费

声明联网搜索的请求沿用软额度：调用前仍检查身份、模型权限与可用余额，不预占额度，也不更改客户端的工具或次数限制。并发请求及单次请求可能超出开始时的剩余额度。

网关按该次请求冻结的模型价格，计算上游实际报告的 token 和联网搜索总次数。搜索按模型配置的每次价格计费；搜索结果条目或工具调用条数不能代替上游明确报告的实际次数。其他工具费用不因此自动计入。

如果请求声明了搜索而上游没有报告次数，或者实际搜索次数存在冲突、没有对应价格，费用标记为未计价，不会猜测次数或将缺失价格当作免费。管理员需要核对上游用量和模型价格；这类记录不能视为已完成准确结算。

计入搜索的响应头为 `X-XHub-Budget-State: soft`、`X-XHub-Billing-Scope: tokens_and_search`、`X-XHub-Tool-Costs: search_metered` 和 `X-XHub-Budget-Guarantee: soft`。日志中的价格快照和费用明细保留计费范围、搜索次数与单价。

回归测试使用本地 HTTP 上游与隔离 PostgreSQL；浏览器测试在两种界面语言下创建并清理测试模型与密钥。这些测试不代表外部供应商的搜索可用性或其返回次数一定完整。
